# Guia de Utilizador

Bem-vindo ao Guia de Utilizador do GamiBot. Este guia irá ajudá-lo a entender como utilizar as funcionalidades do GamiBot no Moodle.

## Índice

1.  [Visão Geral](#visao-geral)
2.  [Como Aceder](#como-aceder)
3.  [Funcionalidades](#funcionalidades)

## Visão Geral

O GamiBot é um assistente virtual integrado no Moodle que utiliza inteligência artificial para ajudar alunos e professores.

![Visão Geral do GamiBot](/images/user-guide/overview.png)
*Figura 1: Interface principal do GamiBot*

## Como Aceder

Para aceder ao GamiBot, procure o ícone de chat no canto inferior direito da sua página do Moodle.

## Funcionalidades

### Esclarecimento de Dúvidas

Pode fazer perguntas sobre o conteúdo do curso, e o GamiBot responderá com base nos materiais disponibilizados.

### Gamificação

O GamiBot inclui elementos de gamificação para tornar a aprendizagem mais envolvente.
