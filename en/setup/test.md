# Testing GamiBot

After installing and configuring GamiBot, it is important to test if everything works correctly. Follow the steps below to test GamiBot in Moodle.

## Feeding GamiBot with content

Add or edit documents in your course so that GamiBot can have content to answer students' questions.

### Add documents

1. Navigate to the course where you want to add documents.
2. Click **Turn editing on** in the top right corner.
3. Click **Add an activity or resource**.
4. Select **File** and click **Add**.
5. Fill out the form with the following information:
   - **Name**: Enter a name for the file.
   - **Description**: Enter a description for the file.
   - **File**: Upload the file you want to add.
6. Click **Save changes**.
7. Wait a few seconds and proceed.

### If you already have documents in the course

Edit, for example, the title or description of existing documents in the course so that GamiBot has content to answer students' questions. You can add a character, save, and then remove it, for example.

## Clarifying a doubt

1. Locate the GamiBot chat icon in the bottom right corner of the screen;
2. Click the icon to open the interaction window.
3. Click "Clarify Doubts".
4. Write a question about the added or edited content in the text field.
5. Click "Send" to send the question to GamiBot.
6. GamiBot will answer the question based on the added or edited content.
7. Click the left arrow in the top left corner of the chat to return to the main menu.

## Summarizing subject matter

1. Click "Summarize Subject".
2. Write the topic of the subject matter you want to summarize in the text field.
3. Click "Send" to send the topic to GamiBot.
4. GamiBot will reply with a summary of the subject.
5. Click the left arrow in the top left corner of the chat to return to the main menu.

## Creating a quiz

1. Click "Create Quizzes".
2. Write the topic and type of quiz you want to create in the text field.
3. Click "Send" to send the query to GamiBot.
4. GamiBot will present the quiz.
5. Answer the quiz.
6. GamiBot will present the quiz result.
7. Click "View Progress" to see the user's progress.
