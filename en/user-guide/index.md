# User Guide

Welcome to the GamiBot User Guide. This guide will help you understand how to use GamiBot features within Moodle.

## Table of Contents

1.  [Overview](#overview)
2.  [How to Access](#how-to-access)
3.  [Features](#features)

## Overview

GamiBot is a virtual assistant integrated into Moodle that uses artificial intelligence to assist students and teachers.

<!--![GamiBot Overview](/images/user-guide/overview.png)-->
*Figure 1: GamiBot Main Interface*

## How to Access

To access GamiBot, look for the chat icon in the bottom right corner of your Moodle page.

## Features

### Doubt Clarification

You can ask questions about the course content, and GamiBot will answer based on the available materials.

### Gamification

GamiBot includes gamification elements to make learning more engaging.
